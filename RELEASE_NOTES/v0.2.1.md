# Thoth v0.2.1

## Changes

- **Menu bar icon matches the app icon.** The menu bar now shows an open-arc
  gauge (`gauge.open.with.lines.needle.33percent`) instead of the old sparkle,
  so it matches the Thoth app icon. It still pulses while Claude Code is
  active.

## Compatibility

Unchanged from v0.2.0: Universal app (Apple silicon and Intel, no Rosetta
needed), macOS 14 or later.
