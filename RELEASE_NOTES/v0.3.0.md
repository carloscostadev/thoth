# Thoth v0.3.0

## Highlights

- **New look.** A monochrome redesign: dark greys with hairline borders,
  monospaced labels and numbers, and colour only where it carries
  information. Light mode follows the system. All colours, type and spacing
  live in one place (`Theme.swift`).
- **New mark.** The Thoth mark replaces the gauge in the menu bar, the
  popover header (symbol and THOTH wordmark) and the app icon.
- **Quieter menu bar.** The mark is full while Claude Code is working and
  dimmed while it sleeps. It no longer pulses, so it costs nothing between
  state changes.
- **Accurate output tokens.** Each response is counted with its final output
  tokens (see Fixes). Costs shown for past periods go up accordingly.
- **Lighter in the background.** Idle CPU drops from about 5% to 0.5% of a
  core, and the memory peak at launch is about 40% lower on a large history.

## Fixes

- Claude Code streams a response over several lines with the same
  `message.id`, and only the last one has the final `output_tokens`. Thoth
  counted the first line, so output tokens were undercounted by about 38% on
  a real history (4.6-7.1% of the cost, depending on the period). Each
  response now counts its final values, also when the lines arrive across
  two reads.
- The project ranking listed every git worktree, Horus parallel worktree,
  `<repo>-worktrees` folder and Claude Code scratchpad as a project of its
  own. They now count under the project they belong to. A session is grouped
  by its first `cwd`, not the one in its last chunk.
- Days, windows and the heatmap are rebuilt after a time zone change, and
  daylight-saving days (23 h and 25 h) are tested.
- The popover's scroll area had no fixed height and could shrink to a line
  and a half; the turns column no longer truncates.
- The interface is English-only, dates included.

## Performance

Release build, real history (about 3,400 transcript files):

| | v0.2.1 | v0.3.0 |
|---|---|---|
| Idle CPU (one core) | ~5% | ~0.5% |
| Memory peak at launch | ~215 MB | ~116-136 MB |
| Today summary, per tick | 0.21 s | 0.005 s |

- The today summary walks the projects tree at most once a minute; in
  between it only re-checks the files already written today.
- The 5-minute scan reads only what was appended to a file that grew, instead
  of re-reading it whole.
- Transcripts are read in 256 KB chunks and listed with their attributes in
  one pass per folder.

## Compatibility

Unchanged: Universal app (Apple silicon and Intel), macOS 14 or later. Launch
at login keeps working; its login item is now named after the app's bundle
identifier, which is the same as before for Thoth.
